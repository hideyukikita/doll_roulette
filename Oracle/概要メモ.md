# 目的
- 今、家で何人もぬいぐるみを飼っています。
- 毎日その中からランダムで1匹と寝ています。
- そんな中、選ばれる頻度が多い子と少ない子が出てしまうので、ルーレットで平等に今日の夜寝る子を決めたいです。

♯ ざっくりの仕様
- まず今飼っているぬいぐるみたちを登録する機能が欲しい
- 一度出たぬいぐるみの子はルーレット対象から外す(もしくはほぼ出ない確率まで落とす)
- ぬいぐるみたち一周したらリセットする
