# 円盤ルーレット 設計仕様

## 1. 概要
文字ルーレットに代わり、円盤が回転するビジュアルルーレットを実装する。

## 2. 決め事

### 2.1 円盤
- **表示対象**: ルーレットを回す時点の「未選択」の子のみ（`dolls.filter(d => !d.is_selected)`）
- **セグメント**: 各子を扇形で表示。色は登録時の色を使用（`utils/colors.ts` で柔らかめに調整）
- **1人用**: 円形1セグメント。名前は3時の位置に表示
- **配置順**: 登録順（created_at 昇順）で円周に並べる。0度（12時）から時計回り
- **回転方向**: 時計回り（clockwise）

### 2.2 針
- **位置**: 画面の上端中央、12時の位置に固定
- **デザイン**: 三角形または矢印で、下向き（円盤の中心を指す）。柔らかいピンク系
- **役割**: 針が指す位置＝当選。つまり「当選の子が12時の場所に来たときに停止」する

### 2.3 当選の扱い
- **停止位置**: 当選した子のセグメントが12時（針の位置）に来たときに回転を止める
- **計算**: セグメントの中心角度と回転角から、停止時の transform を算出

### 2.4  animation
- **回転時間**: 約 2.5 秒（SPIN_DURATION_MS）
- **回転量**: 5〜8 回転 + 当選位置への微調整
- **イージング**: 終盤で減速（ease-out）

### 2.5 結果表示
- **表示時間**: 当選後、結果を約 3 秒表示
- **表示内容**: 従来通り（名前・画像・色。二回目当選時は「二回目！」付き）
- **3秒後**: 当選者を除いた円盤に再描画。残り 0 人の場合は「全員一周」表示へ

### 2.6 エッジケース
- **残り1人のとき**: 円盤は1セグメント（円形）。名前は3時の位置に表示。回転して停止し、結果を3秒表示してから「全員一周」へ
- **allDone のとき**: すでに全員当選済み。円盤は表示せず「全員一周したよ！」のみ

### 2.7 ボタン・UI
- **回転中**: ボタン文言は「誰が出るかな？」「ゆちゅきと寝たいなぁ」「楽しみ！！」をランダムで表示（低確率で「マックのポテト、、、」も）
- **結果表示中**: ボタン文言は「おめでとう！」「今日はパーティー！」「お外連れてって！」をランダムで表示。ボタンは無効

## 3. フロー
1. ユーザーが「ルーレットを回す」をクリック
2. API で当選者を取得
3. 円盤が回転開始（未選択の子の円盤）
4. 約 2.5 秒後、当選者のセグメントが 12 時に来るように停止
5. 結果を 3 秒表示
6. 3 秒後、当選者を除いた円盤に再描画（getDolls で最新取得）
7. 残り 0 人の場合は「全員一周したよ！リセットしてね」に切り替え
