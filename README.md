# かぞくたちルーレット

飼っているぬいぐるみたちを平等に選び、一緒に寝る子を楽しく決めるアプリです。

**実行環境**: WSL2 (Ubuntu) / Windows 上の Linux で動作します。

---

## 機能一覧

### 家族管理
- **登録**: 名前・色・画像（任意・複数可）で新しい子を追加
- **一覧**: 登録済みの子を表示。行をタップすると詳細が手前に表示される。一覧のサムネイルは代表画像（サブ画像の追加・削除では変わらない）
- **詳細**: 名前・色・代表画像（1枚）・サブ画像（複数）を表示。ここから編集・削除
- **編集**: 詳細内で名前・色・代表画像の差し替え・削除、サブ画像の追加・削除が可能
- **削除**: 詳細内の削除ボタンから削除（確認あり）
- **色**: 茶色・白・ピンク・グレー・青・緑・黄・黒・オレンジ・えんじ・水色・ミント・紫・赤・その他

### お出かけ日記
- **登録**: 場所・日付・一緒に行った家族（複数可）・写真（複数可）・コメント
- **一覧・詳細**: 一覧で概要表示、**行をタップすると手前にオーバーレイで詳細表示**。詳細で写真をタップすると画像全体を表示。写真削除時は確認あり
- **編集・削除**: 場所・日付・一緒に・コメントの編集、写真の追加・削除、日記ごと削除

### ルーレット
- **円盤ルーレット**: 扇形セグメントが回転し、当選者が12時の針の位置に来て停止
- **当選表示**: 回転停止後、結果を3秒表示。**代表画像・サブ画像を合わせた中からランダムで1枚**と登録色で当選者を表示
- **再描画**: 3秒後、当選者を除いた円盤に再描画
- **二回目当選**: ラッキーで再当選した場合は「二回目！」と派手な演出
- **全員一周**: 最後の一人の結果を3秒表示してから「全員一周したよ！」に切り替え
- **ボタン文言**: 回転中・結果表示中でランダムメッセージ。結果表示中はボタン無効
- **結果表示中**: 3秒間はボタンが無効になり、自動で円盤に戻るまで待つ

### 当選履歴・リセット
- **当選履歴**: その回の当選者を一覧表示（**その時に出た画像**・登録色付き）
- **リセット**: 全員の選択状態と当選履歴をクリアし、もう一度ルーレットできるようにする

## 起動方法

### 前提条件
- Docker / Docker Compose がインストール済み
- プロジェクトルートに `.env` があること（`.env.example` をコピーして編集）

### 1. 環境変数の設定

```bash
cp .env.example .env
# .env を編集し、POSTGRES_PASSWORD などを設定
```

### 2. 起動

```bash
docker compose up -d
```

### 4. アクセス

- **フロントエンド**: http://localhost:5173
- **API**: http://localhost:3000

## スマホからの接続方法

同じ Wi-Fi に接続したスマートフォンからアプリを使えます。

### WSL2 (Ubuntu) で実行している場合【要ポート転送】

WSL2 は Windows 内の仮想 Linux のため、スマホからアクセスするには **Windows でポート転送の設定が必要**です。そのままでは Windows の IP でアクセスしても WSL2 の 5173/3000 には届きません。

**必須**: `scripts/Connect-WSL.ps1` を **管理者として開いた PowerShell** で実行してください。

```powershell
# 管理者 PowerShell を開き、プロジェクトルートで実行
.\scripts\Connect-WSL.ps1
```

このスクリプトは、Windows が受け取った 5173/3000 番ポートの通信を WSL2 に転送します。**PC や WSL2 を再起動したあとはスクリプトを再実行**してください（WSL2 の IP が変わります）。

### 手順

#### 1. ポート転送を設定する（WSL2 の場合のみ）

上記の `Connect-WSL.ps1` を実行。

#### 2. PC（Windows）の IP アドレスを確認する

**WSL2 の場合**（上記参照）: Windows ホストの IPv4 を使用

**Linux / Mac で直接実行している場合**:
```bash
hostname -I | awk '{print $1}'
```

#### 2. API の URL（任意）

スマホから開く場合、**未設定でもOK**です。フロントは「同じホスト:3000」を自動で API 向き先に使うため、`http://（PCのIP）:5173` で開けば API も同じ IP の 3000 番に届きます。日をまたいで IP が変わった場合は、その日の PC の IP で開き直してください。

必要なら `.env` で明示もできます（`YOUR_PC_IP` を実際の IP に置き換え）:

```
VITE_API_BASE_URL=http://192.168.1.100:3000
```

#### 3. コンテナの起動

```bash
docker compose up -d
```

環境変数を変更した場合は再起動してください。

#### 4. スマホのブラウザでアクセス

スマホを **PC と同じ Wi-Fi** に接続し、ブラウザで次の URL を開きます:

```
http://192.168.1.100:5173
```

（`192.168.1.100` はあなたの PC の IP に置き換えてください）

### 注意点

- PC とスマホは **同じ Wi-Fi ネットワーク** に接続されている必要があります
- **WSL2 の場合**: Windows のファイアウォールで 5173 番・3000 番ポートがブロックされていないか確認してください。接続できないときは、Windows の「ファイアウォールによるアプリの許可」で Node / Docker を許可するか、一時的にファイアウォールを無効にして試してください
- PC の IP は再起動やネットワーク変更で変わる場合があります。接続できないときは再度確認してください

## 使い方

### 1. かぞくを登録する
1. 「かぞく一覧」ページを開く
2. 名前と色を入力して「追加する」をクリック
3. 登録した子は一覧に表示されます
4. 一覧の行をタップすると詳細が開きます。詳細から編集・削除ができます

### 2. ルーレットを回す
1. 「ルーレット」ページを開く
2. 「ルーレットを回す」ボタンを押す
3. 円盤が約2.5秒回転したあと、当選者が画像付きで表示されます
4. 結果は3秒間表示され、その間はボタンが「おめでとう！」などに変わります
5. 3秒後、当選者を除いた円盤に切り替わり、当選履歴に追加されます

### 3. 全員一周したらリセット
1. 全員が1回以上当選すると「全員一周したよ！」と表示されます
2. 「リセット」ボタンを押す
3. 確認ダイアログで「OK」を選択
4. 当選履歴がクリアされ、もう一度ルーレットで選べるようになります

### 4. お出かけ日記（任意）
1. 「お出かけ日記」ページで「新しいお出かけを登録」から、場所・日付・一緒に行った家族・写真・コメントを入力して登録
2. 一覧の項目をタップすると詳細表示。写真をタップすると画像全体を表示。編集・削除も可能

## UI・デザイン

- **配色**: 柔らかいトーン（stone／violet／rose／amber 系）
- **ぬいぐるみの色**: 円盤上で視認しやすいよう、白・黄などは調整済み

## 技術スタック

- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **Backend**: Node.js (Express) + TypeScript + Multer（画像アップロード）
- **Database**: PostgreSQL
- **Infrastructure**: Docker Compose（postgres / backend / frontend + uploads ボリューム）
