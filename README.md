# かぞくたちルーレット

飼っているぬいぐるみたちを平等に選び、一緒に寝る子を楽しく決めるアプリです。

---

## 機能一覧

### 家族管理
- **登録**: 名前と色を選んで新しい子を追加
- **編集**: 登録済みの子の名前・色を変更
- **削除**: 不要な子を削除

### ルーレット
- **文字ルーレット**: 名前が切り替わる演出で当選者を決定
- **当選表示**: 登録時の色で当選者を表示
- **二回目当選**: ラッキーで再当選した場合は「二回目！」と派手な演出
- **全員一周**: 最後の一人の結果を3秒表示してから「全員一周したよ！」に切り替え

### 当選履歴・リセット
- **当選履歴**: その回の当選者を一覧表示（登録色付き）
- **リセット**: 全員の選択状態と当選履歴をクリアし、もう一度ルーレットできるようにする

## 起動方法

### 前提条件
- Docker / Docker Compose がインストール済み
- プロジェクトルートに `.env` があること（`.env.example` をコピーして編集）

### 1. 環境変数の設定

```bash
cp .env.example .env
# .env を編集し、POSTGRES_PASSWORD などを設定
```

### 2. 起動

```bash
docker compose up -d
```

### 3. アクセス

- **フロントエンド**: http://localhost:5173
- **API**: http://localhost:3000

## スマホからの接続方法

同じ Wi-Fi に接続したスマートフォンからアプリを使えます。

### 手順

#### 1. PC の IP アドレスを確認する

**Windows（WSL2 の場合）**:
```powershell
ipconfig
```
「イーサネット アダプター」または「ワイヤレス LAN アダプター」の **IPv4 アドレス** を確認（例: `192.168.1.100`）

**Linux / Mac**:
```bash
hostname -I | awk '{print $1}'
# または
ip addr show | grep "inet " | grep -v 127.0.0.1
```

#### 2. `.env` で API の URL を設定

スマホから接続する場合、フロントエンドは「PC の IP 経由で API にアクセス」する必要があります。

`.env` に以下を追加または変更します（`YOUR_PC_IP` を実際の IP に置き換え）:

```
VITE_API_BASE_URL=http://192.168.1.100:3000
```

#### 3. コンテナを再起動

環境変数を変更したら、フロントエンドを再ビルドするため再起動します:

```bash
docker compose down
docker compose up -d
```

#### 4. スマホのブラウザでアクセス

スマホを **PC と同じ Wi-Fi** に接続し、ブラウザで次の URL を開きます:

```
http://192.168.1.100:5173
```

（`192.168.1.100` はあなたの PC の IP に置き換えてください）

### 注意点

- PC とスマホは **同じ Wi-Fi ネットワーク** に接続されている必要があります
- ファイアウォールで 5173 番・3000 番ポートがブロックされていないか確認してください
- PC の IP は再起動やネットワーク変更で変わる場合があります。接続できないときは再度確認してください

## 使い方

### 1. かぞくを登録する
1. 「かぞく一覧」ページを開く
2. 名前と色を入力して「追加する」をクリック
3. 登録した子は一覧に表示されます
4. 名前や色を変えたいときは「編集」ボタンから変更できます

### 2. ルーレットを回す
1. 「ルーレット」ページを開く
2. 「ルーレットを回す」ボタンを押す
3. 名前が切り替わる演出のあと、当選者が表示されます
4. 当選履歴に追加されます

### 3. 全員一周したらリセット
1. 全員が1回以上当選すると「全員一周したよ！」と表示されます
2. 「リセット」ボタンを押す
3. 確認ダイアログで「OK」を選択
4. 当選履歴がクリアされ、もう一度ルーレットで選べるようになります
