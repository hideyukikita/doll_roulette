# Step 3 動作確認（フロントエンド 登録・一覧）

## 概要
- フロントエンドで**かぞくたちの登録**（名前・色選択）と**一覧表示・削除**ができます。
- バックエンド API（Step 2）と連携します。

---

## 1. 起動

```bash
docker compose up -d
```

ブラウザで **http://localhost:5173** を開く（スマホの場合は portproxy 設定後、`http://<WindowsのIP>:5173`）。

---

## 2. 画面確認

### 2.1 表示内容
- **タイトル**: 「かぞくたちルーレット」
- **新しい子を追加**: 名前（テキスト）、色（プルダウン）、「追加する」ボタン
- **登録済みのかぞくたち**: 一覧（名前・色）、各行に「削除」ボタン

### 2.2 登録
1. 名前を入力（例: くまさん）
2. 色を選択（茶色・白・ピンク・グレー・青・黄・黒・その他）
3. 「追加する」をクリック
4. 一覧に 1 件追加されること

### 2.3 削除
1. 一覧の「削除」をクリック
2. 確認ダイアログで「OK」
3. 該当行が一覧から消えること

### 2.4 エラー時
- API が止まっている・URL が違う場合: 「一覧の取得に失敗しました」などが表示される
- バックエンドと DB が起動しているか確認: `docker compose ps`  
- フロントの API 先: `.env` の `VITE_API_BASE_URL`（Docker 利用時はルートの `.env` がコンテナに渡る。フロントはビルド時に `VITE_*` が埋め込まれるため、**変更した場合はフロントを再ビルド**する）
