# Step 4 動作確認（ルーレット演出 & 当選ロジック）

## 概要
- **ルーレット**: 回すと名前が回転し、当選者が決まる演出。
- **ロジック**: 未選択の子は高確率、一度選ばれた子はめちゃめちゃ低確率（design パターンB）。
- **UI**: 残り○人 / 全○人、当選履歴（日時付き）。全員選ばれたら「全員一周したよ！」。
- **名称**: 表示は「かぞくたちルーレット」に統一済み。

---

## 1. 起動

```bash
docker compose up -d
```

ブラウザで **http://localhost:5173** を開く。

---

## 2. 画面確認

### 2.1 ナビ
- 上部に「ルーレット」「かぞく一覧」のタブ。クリックで切り替え。

### 2.2 ルーレット画面
- **残り○人 / 全○人**: 未選択の人数と登録総数。
- **ルーレットを回す**: クリックで約2.5秒名前が回転し、当選者が表示される。
- **全員一周**: 全員が1回以上選ばれたら「全員一周したよ！」と表示され、回すボタンはそのまま（再抽選は低確率で可能）。
- **当選履歴**: 直近の当選者と日時。

### 2.3 かぞく一覧
- これまで通り登録・一覧・削除。

---

# ルーレットを回す
curl -s -X POST http://localhost:3000/api/roulette/spin

curl -s http://localhost:3000/api/histories
