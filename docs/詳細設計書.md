## 2. データベース（詳細）

テーブル定義・ER・インデックスは [db-structure.md](db-structure.md) を参照。

### 2.1 主要なリレーション

- dolls 1 → N doll_images（サブ画像）
- dolls 1 → N histories（当選履歴）。histories.doll_image_url は当選時に表示した画像
- dolls N ←→ M outings（outing_dolls: お出かけに一緒に行ったかぞく）
- outings 1 → N outing_images（写真）

### 2.2 ルーレットで使用するフラグ

- dolls.is_selected: 当選済みなら true。リセットで false に一括更新。
- 抽選: 未選択は重み 1、選択済みは重み 0.008（rouletteService）。

## 3. API 詳細

### 3.1 かぞく（/api/dolls）

| メソッド | パス | 説明 | 備考 |
|----------|------|------|------|
| GET | /api/dolls | 一覧 | image_urls は doll_images から取得して付与 |
| POST | /api/dolls | 登録 | body: { name, color } |
| PUT | /api/dolls/:id | 更新 | body: { name, color } |
| POST | /api/dolls/:id/image | 代表画像1枚 | multipart, field: image |
| POST | /api/dolls/:id/images | サブ画像複数 | multipart, field: images |
| POST | /api/dolls/:id/images/remove | 画像1枚削除 | body: { image_url } |
| DELETE | /api/dolls/:id | 削除 | CASCADE で doll_images, histories 等も削除 |

### 3.2 お出かけ（/api/outings）

| メソッド | パス | 説明 | 備考 |
|----------|------|------|------|
| GET | /api/outings | 一覧 | 画像URL一覧・一緒に（doll_ids）付き |
| GET | /api/outings/:id | 詳細 | 同上 |
| POST | /api/outings | 登録 | body: place, outing_date, comment, doll_ids |
| PUT | /api/outings/:id | 更新 | body: place, outing_date, comment, doll_ids |
| POST | /api/outings/:id/images | 写真複数追加 | multipart, field: images |
| POST | /api/outings/:id/images/remove | 写真1枚削除 | body: { image_url } |
| DELETE | /api/outings/:id | 削除 | CASCADE で outing_dolls, outing_images も削除 |

### 3.3 ルーレット・履歴・リセット

| メソッド | パス | 説明 | 備考 |
|----------|------|------|------|
| POST | /api/roulette/spin | 抽選1回 | 未選択から重み付きで1体選択。当選画像は代表 or サブからランダム1枚。histories に doll_image_url 保存。全員選択済みなら allDone を返す。 |
| GET | /api/histories | 当選履歴 | query: limit（省略可）。doll_name, doll_color, doll_image_url, selected_at を返す。 |
| DELETE | /api/histories/:id | 履歴1件削除 | 対応する doll の is_selected を false に戻し、ルーレットに復活させる。 |
| POST | /api/reset | リセット | 全 dolls の is_selected を false に。全 histories を DELETE。 |

## 4. 画面・コンポーネント詳細

### 4.1 DollsPage

- 上部: 登録フォーム（名前・色・画像任意）。送信で POST /api/dolls → 必要なら POST /api/dolls/:id/image または /images。
- 一覧: 行はサムネイル（代表画像優先）・名前・色。行タップで detailId を設定し、オーバーレイで詳細表示。
- 詳細オーバーレイ: 代表画像・サブ画像を表示。画像タップで selectedImageUrl を設定し、全画面画像オーバーレイ。**全画面表示時に「ダウンロード」ボタンで端末に保存可能**。編集モード時は代表・サブの削除・追加可能。削除ボタンで確認後 DELETE。

### 4.2 OutingsPage

- 登録: 場所・日付・一緒に（doll_ids）・写真・コメント。POST /api/outings → 必要なら POST /api/outings/:id/images。
- 一覧: 行タップで detailId を設定し、オーバーレイで詳細。詳細内で写真タップで selectedImageUrl で全画面表示。編集は詳細内で PUT と画像追加・remove。写真削除時は確認ダイアログ。

### 4.3 RoulettePage

- 残り/全表示・リセットボタン。
- ルーレット円盤（RouletteWheel）または結果表示（3秒間）。結果表示中はボタン無効。
- 当選履歴: 一覧の行タップで detailHistoryId を設定し、オーバーレイで詳細。詳細で画像タップで selectedImageUrl で全画面表示。削除は詳細内から。

### 4.4 RouletteWheel

- props: dolls（セグメント用）, winnerId（当選者ID）, spinning, onSpinComplete。
- 扇形セグメントを円形に配置。spinning 時に winnerId のセグメントが12時位置に来るように回転して停止。停止後に onSpinComplete を呼ぶ。

## 5. 主要処理フロー

### 5.1 ルーレット抽選（POST /api/roulette/spin）

1. 未選択の dolls を取得。0件なら「全員選択済み」で allDone を返す。
2. 重み付き抽選（未選択=1, 選択済み=0.008）。1体決定。
3. 当選者の画像を決定: image_url と doll_images の image_url を合わせた配列からランダム1枚。無ければ null。
4. histories に INSERT（doll_id, doll_image_url, selected_at）。
5. 当選者の dolls.is_selected を true に UPDATE。
6. 当選者情報（doll, luckySecond 有無）と doll_image_url を返す。

### 5.2 リセット（POST /api/reset）

1. 全 dolls の is_selected を false に UPDATE。
2. 全 histories を DELETE。

### 5.3 画像アップロード（代表・サブ・お出かけ写真）

1. Multer で multipart を受信。保存先は /uploads 配下（dolls/outings 等のサブディレクトリ）。
2. 保存したパス（例: /uploads/dolls/xxx.jpg）を DB に保存（dolls.image_url, doll_images.image_url, outing_images.image_url 等）。
